How It Actually Runs

Input → real
computation → real output.

1

Fill in one Excel row

Drug name, and either a SMILES (small molecule) or a FASTA sequence (mAb, oligonucleotide, peptide) — the engine branches correctly on molecule class, not a one-size-fits-all path.

2

The engine actually computes

Real 50-receptor off-target QSAR panels trained live on ChEMBL bioactivity data, real PBPK ODE simulation, real DLVO colloidal-stability physics, real AutoDock Vina docking — minutes of genuine work, not a lookup table.

3

Get a full report

Interactive HTML dashboard, PDF report, completed Excel — every number traceable to the run that produced it.

Why We're Building This Openly

Audit it.
Break it.
Tell us what's wrong.

This is a research prototype, not a clinical tool. Of the drugs run through the pipeline's own internal scoring so far, most score MARGINAL — no drug has produced a clean PASS yet. A full engineering & scientific-integrity audit ships in the repo, updated every time an issue is found and fixed — including two data-integrity bugs found and fixed this week by actually running the pipeline and chasing anomalies instead of trusting a green build.
